## 📌 About the Assignment

This assignment was completed by modifying and integrating **provided source code**.

The main objective was to combine the provided **Login & Registration** project with another project containing **CRUD operations**.

---

## 🎯 Work Completed

### 🔄 OleDb to SQL Server

The existing **OleDb** database connectivity was changed to **SQL Server using SqlClient**.

### ⚙️ App.config Modification

The `App.config` file was modified to use the required **SQL Server connection configuration**.

### 🔗 Project Integration

The two faculty-provided projects were merged into a single application.

```text
Login & Registration
        │
        ▼
   Integrated Project
        │
        ├── CRUD Operations
        └── Other Provided Functions
```
